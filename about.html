// About the Generator

This is a simple reference generator for IIE students. Whereby they can easily create Harvard-style references for their assignments.

A precision-focused, developer-styled tool for accurate IIE Harvard Anglia academic referencing.

01. Purpose & Vision

Referencing according to the IIE (Independent Institute of Education) Harvard Anglia standard demands strict precision—from punctuation marks to italicisation rules. This tool was built to streamline the citation process for students and researchers, offering both quick automated metadata extraction and granular manual entry.

02. Core System Features

  • Dual-Mode Data Entry: Auto-extract metadata from web URLs or manually fill form fieldsets.
  • IIE Anglia Compliance: Formatted specifically to conform to IIE Harvard Anglia referencing requirements.
  • Instant Clipboard Export: Copy in-text citations and full reference entries with a single click.
  • Responsive IDE Interface: retro-inspired codebase UI for clean navigation.

03. Understanding IIE Harvard Anglia

The IIE Harvard Anglia style is a specific adaptation of the Harvard referencing system. It requires precise formatting for:

  • In-Text Citations: Incorporating author surnames and publication years directly into the body text (e.g., Smith, 2024: 15).
  • Reference List Entries: Arranging full source details alphabetically at the end of the document, utilizing exact casing, italics, and retrieval details for online sources.
